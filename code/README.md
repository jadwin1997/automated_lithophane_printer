# Lithophane Maker, CLI Interaction, and Custom GCODE
This code searches within the current directory and processes images. Those images are converted to a lithophane using standard python libraries.
This 3D model is sliced using the bambu labs CLI. Output GCODE is modified to contain an item removal function that "knocks" the print off of the bed.
