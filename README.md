#Automated 3D Lithophane Printing System
##Summary
This project intends to create an automated lithophane creation pipeline using a Bambu Labs P1S 3D printer.
Using custom G-Code, we can let the bed cool down and use the printers head to knock prints off, allowing us to start another print with no human interaction.
The input for this system will be a directory to photos. Within this directory will be a text file containing the settings for model slicing/lithophane generation such as output size (X,Y,Z), target plastic use, or cropping settings. Using the AMS system for automated filament refilling would allow for 100+ 30 gram lithophanes to be printed in a single continuous printing run. 

If successful, I will look into creating an automated etsy page that will take orders and automatically start prints. Then, the end user (me) will just have to pack and ship orders. 
Perhaps identifiers could be added to the model such as a qr code that would allow me to organize orders at scale if necessary.
